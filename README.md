## ✨ What's inside

This repo is an early scaffold (the page still renders the Vite "Hello Vite!" hero). What is already set up:

- **Vite 8** dev server and production build
- **Tailwind CSS 3** compiled through PostCSS (`postcss.config.cjs`), with `darkMode: "class"` enabled
- **Global styles** in `style.css` - Montserrat as the base font and heading sizes reset to browser defaults
- **Complete favicon set** under `images/favicon/` - Apple touch icon, Android Chrome icons, Safari pinned tab, Windows tiles (`browserconfig.xml`) and a `site.webmanifest`
- **Logo assets** for Vite and JavaScript in `images/logo/programming-lang/`

## 🚀 Quick Start

Node 20.19+ / 22.12+ is required by Vite 8 (verified on Node 26).

```bash
npm install
npm run dev
```

Vite serves the page at `http://localhost:5173`. Edit `index.html` and `style.css` to build out the landing page.

## 📦 Scripts

| Script            | Description                              |
| ----------------- | ---------------------------------------- |
| `npm run dev`     | Vite development server with HMR         |
| `npm run build`   | Production build into `dist/`            |
| `npm run preview` | Preview the production build locally     |

## 🏗️ Structure

```
images/
├── favicon/                 # Full favicon / PWA icon set + site.webmanifest
└── logo/programming-lang/   # vite.svg, javascript.svg
index.html                   # Page markup (Tailwind utility classes)
style.css                    # Tailwind directives + global styles
tailwind.config.cjs          # darkMode: "class", content globs
postcss.config.cjs           # Tailwind PostCSS plugin
```

## 🚀 Deployment

`npm run build` outputs a static site to `dist/` that can be served from any static host.
